# أبو طارق الغاوي – حلاوة الجبن

مشروع لعبة الويب مغلف كتطبيق Android باستخدام Capacitor.

## بناء APK
1. ارفع جميع محتويات هذا المجلد إلى مستودع GitHub.
2. افتح تبويب Actions.
3. اختر Build Android APK ثم Run workflow.
4. بعد نجاح البناء، افتح نتيجة التشغيل ونزّل Artifact باسم Abu-Tarek-Game-APK.
5. فك ضغط الملف لتحصل على app-debug.apk.

يمكن أيضاً أن يبدأ البناء تلقائياً عند رفع الملفات إلى الفرع main.
